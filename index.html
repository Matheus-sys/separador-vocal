    Sobre, créditos e licenças

    Ferramenta gratuita para estudo de canto. A separação roda no próprio navegador com ONNX Runtime Web.

    • Modelo de alta qualidade: Mel-Band RoFormer Duality + KARA 2 student, de musetric (Apache-2.0).
    • Modelo leve: MDX-Net Kim Vocal 2, do projeto Ultimate Vocal Remover.
    • Tom e velocidade: SoundTouch JS (LGPL-2.1). MP3: lamejs (LGPL-3.0).

    Use com músicas que você tem direito de usar para estudo. Nada é enviado para servidor.
